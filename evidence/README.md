# Public network evidence

These files were generated by reading actual objects from the public Swarm API. They contain public references and clearly labeled synthetic sightings, not account credentials.

- `first-publication.json`: independent CLI read at sequence index 0, validating the first sighting and the 1,310,793-byte photograph against their declared SHA-256 and size.
- The stable [notebook link](https://fieldnote-reader-hrsh22.vercel.app/#notebook=b624c672831973e1ddcbce3b75f6f18d9dba31febca86d50fd11a966051cdba8) resolves the latest signed index, which may advance after a saved snapshot.

Reproduce without logging in:

```sh
npm ci
npm run verify:notebook -- b624c672831973e1ddcbce3b75f6f18d9dba31febca86d50fd11a966051cdba8
```

The writer used the dedicated Fieldnote Demo Swarm ID account and the configured sponsored gateway. No personal drive was created. The local Bee, keeper and Cloudflare tunnel were stopped during the test.

The Common Kingfisher photograph is by **Tony Wood**, taken in England in 2012, licensed **CC BY 2.0**, and uploaded unchanged. It illustrates a synthetic observation and is not evidence of a real sighting at the demo coordinates. Source: [Wikimedia Commons file description](https://commons.wikimedia.org/wiki/File:Alcedo_atthis_-England-8.jpg). License: [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Attribution also travels inside the Swarm sighting record and is rendered by both applications.

Automated test results and browser acceptance status are recorded in [verification notes](../docs/VERIFICATION.md). These are local review artifacts, not an official judging attempt.

## Second publication and exact stored objects

- `second-publication.json` verifies both records at sequence index 1, including the original photograph. The address reference is unchanged.
- `objects/` contains the exact UTF-8 bytes fetched from `/bytes` for the descriptor, both notebook indexes and both sighting records. Filenames are their public Swarm references. Do not reformat these files: whitespace changes their recorded byte length and SHA-256.
- `objects-manifest.json` records retrieval time, object format/version, size and checksum. The latest index's `previous` field equals the first publication's index reference.
- A new Chrome incognito session opened the same reader link and displayed both records and the photograph without a writer session or Swarm ID login.

The photograph itself is not duplicated in Git. Its content reference, exact size, checksum, source and license are available in the record and verification outputs.
